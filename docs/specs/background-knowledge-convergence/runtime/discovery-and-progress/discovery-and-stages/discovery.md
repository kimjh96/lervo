# Discovery

Startup, canonical event changes, and a 60-second idle inspection discover existing debt and the last ordinary source edit. Event changes use a 30-second quiet window with a 60-second maximum delay. A bounded one-second event-head check supplements filesystem notifications.

Only one repository cycle runs at a time. A pending wakeup survives an active cycle.

The seven stages are `assessment`, `canonical_review`, `canonical_integration`, `normalization_generation`, `normalization_review`, `normalization_apply`, and `lifecycle_verification`.
