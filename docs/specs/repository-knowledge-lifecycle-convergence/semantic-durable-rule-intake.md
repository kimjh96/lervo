# Semantic durable-rule intake contract

## Automatic intake gate

The reusable grounding contract may carry one exact-key durable-instruction assessment. An authorized managed or explicit intake consumer may invoke the separate materializer only when all conditions hold:

- An explicit user directive and repository duration.
- Additive, low-risk behavior and unambiguous scope.
- A complete bounded comparison catalog and no conflict.
- High confidence, ready grounding, and no ambiguity.

Examples, quotations, hypotheticals, complaints, questions, current-task commands, inferred preferences, replacements, removals, risky policy, incomplete catalogs, and worker-wide scope fail the automatic gate.

## Consumer authority

ADR-0327 supersedes automatic intake for direct unmanaged terminals: prompt preparation performs retrieval only, emits `unmanaged_terminal_retrieval_only`, and never calls the materializer.

ADR-0376 installs the separate authority-bearing consumer through `knowledge instruction intake` and exact-hash `knowledge instruction review`. It stores no raw request, never lets the hook approve or write, and removes bounded active candidate state after apply or reject.
