# Recognized repository agent surfaces

Recognized surfaces include AGENTS hierarchy; Claude memory, rules, skills, commands, agents, and settings; Codex rules, hooks, configuration, and custom agents; Agent Skills; and supported third-party entrypoints.

Behavioral instructions, textual portable-skill files, and reviewable workflows may be semantic sources. Binary portable-skill resources are supported opaque resources: migration binds their path, size, and content hash while keeping their bytes out of semantic units and compiler envelopes.

Execution policy, hooks, client and tool configuration, provider subagents, local memory, and unknown `.agents/**` remain inventory-only. `.agents/rules/**` is not standard.

Migration may merge only versioned Lervo terminal handlers into project arrays after exact approval. Existing provider semantics are not translated.
