# Fixed-size instruction routing

AGENTS contains one fixed-size registry bootstrap rather than one route per source. Task purpose and target paths select current instructions and portable skills through repository knowledge query. Adding, removing, or promoting an independently addressed source does not edit AGENTS.

Schema-1 enumerated routes and the obsolete promoted-pattern block migrate to schema 2. A managed-block-only change is safe upgrade state and preserves all surrounding user bytes. Any coincident user-region rewrite is applied only after the independent lifecycle review or foreground cross-check of the exact plan. Immediate replanning after an applied migration is current.
