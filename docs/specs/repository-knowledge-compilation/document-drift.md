# Document Drift and Historical Documents

This specification defines how `lervo knowledge lint` reports drift between repository documents and the repository they describe, and how historical documents stay out of current navigation. [ADR-0464](../../decisions/knowledge/documents/0464-report-document-drift-and-historical-documents.md) defines the exact rules.
