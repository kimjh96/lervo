# GLA14: Packed product-host protocol

`lervo application capabilities --json` exposes one versioned, effect-free capability report. It inventories existing workforce, operating, and collaboration routes and names their result contracts, output forms, effects, authority, and availability. Product UI, product databases, unattended scheduling, dynamic graph mutation, implicit approval, and unmanaged terminal execution are explicitly unsupported.

The protocol uses the sole public `@lervo/cli` artifact; workspace-private application packages are not prematurely published. The packed external-consumer fixture imports no workspace package. Through CLI commands, it creates one local agent, workstream, and assignment, then reads objective, graph, budget, thread, inbox, and static board without a Hub, provider, or connector effect. Existing domain commands remain the only policy and mutation owners.

## Acceptance

Focused tests must cover deterministic discovery, effect and authority classification, connector adapter requirements, and explicit non-capabilities. The real packed consumer must prove the local product-host journey and absence of private-package installation.

Quality, type, package-boundary, build, full tests, documentation and knowledge lifecycle, foundation checks, and task-base release completion must pass with reviewed minor release intent.
