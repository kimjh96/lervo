# GLA15: Project operating attention

One deterministic read-only projection covers current workstream decisions, approvals and blockers, canonicalization review candidates, and repository-knowledge lifecycle issues. It explicitly reports action owner, user authority, blocking state, source coverage, and unavailable-source meaning. It neither owns nor acknowledges the underlying work.

Direct terminal preparation includes a bounded cache-backed form without another model call or full lifecycle scan. Default product-host protocol v1 stays unchanged; explicit protocol v2 appends `operating_attention.inspect`.

Completed or rejected canonicalization candidates become eligible for the existing exact state-retention policy; unresolved candidates remain protected. A stale candidate permits exact-hash rejection, never defer or promotion.

## Acceptance

Focused tests must cover deterministic ordering and bounds, degraded-source availability, stale-candidate safety, terminal retrieval continuity, and state retention. The real packed consumer must discover both protocol versions and invoke attention without workspace-private imports. Ordinary repository completion gates must pass.
