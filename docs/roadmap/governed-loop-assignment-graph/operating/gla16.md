# GLA16: Workstream goal projection

The verified workstream is the one repository root goal; its bound assignments form the execution DAG. A storage-free application report retains exact source coordinates, progress, explicit lifecycle status, completion readiness, and contradictions. It creates no second goal or task authority and never infers completion.

`lervo loop goal` exposes the read-only report. Explicit product-host protocol v2 appends `operating_goal.inspect`; default v1 stays unchanged. Independent nested goals, dynamic topology, provider startup, and unattended scheduling remain unsupported.

## Acceptance

- Pure tests must cover coordinate matching, active progress, false authority flags, and inconsistent completion.
- CLI tests must prove no managed execution.
- The packed external consumer must discover and invoke the route.
- All ordinary repository completion gates must pass.
