# GLA4: Minimal local operating client

`@lervo/operating-client` is a read-only graphical reference client over the exact governed-work report, with no storage, Hub, provider, or mutation dependency. It projects report evidence into a board view model and renders deterministic, self-contained HTML. `lervo loop board` supplies the report; the generated document has no script, form, server, network dependency, or state-changing control.

## Acceptance

Focused tests must cover:

- Assignment and dependency projection.
- Attempt, approval, completion, action, and resource visibility.
- Deterministic escaped HTML and explicit evidence limitations.
- No mutation-port invocation.
- Invalid-report exit preservation.

Quality, type, package-boundary, build, full tests, documentation and knowledge lifecycle, foundation checks, and task-base release completion must pass with reviewed minor release intent.
