# GLA6: Assignment interactions, mentions, and inboxes

`assignment.handoff.recorded` remains the canonical route, without a collaboration database or second task authority. A provider-neutral mention plan resolves exact agent, unique active role, recorded manager, reviewer-role, or verifier-role targets. It binds the current workstream, assignment revision, source agent, lease, request digest, artifact coordinates, and context evidence. Exact apply delegates to the existing workforce handoff transition.

The storage-free application contract and pure work-controller projection rebuild deterministic assignment threads and recipient inbox items from current-workstream handoffs. They exclude bodies and distinguish recorded routing from unobserved delivery and acknowledgment. Read-only CLI routes and the local board consume the same report.

External connectors, team expansion, provider switching, implicit assignment creation, and deliberation startup remain outside GLA6.

## Acceptance

Focused tests must cover:

- Exact agent, unique role, and manager resolution.
- Ambiguous, inactive, self, disallowed-role, workstream, and lease failures.
- Exact plan/apply; content-free thread and inbox projection; missing identity invalidation.
- Read-only CLI inspection and no delivery or acknowledgment inference.

Quality, type, package-boundary, build, full tests, documentation and knowledge lifecycle, foundation checks, and task-base release completion must pass with reviewed minor release intent.
