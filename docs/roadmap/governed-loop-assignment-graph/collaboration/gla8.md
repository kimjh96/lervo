# GLA8: Authenticated assignment connector delivery

GLA8 binds one artifact from a canonical assignment handoff to a provider-neutral connector, internal destination, and content-bound chat publication permit. A pure route plan derives exact outbound and attempt identities without bodies or native platform identifiers. The stock CLI can plan locally but has no external-delivery authority.

Exact apply re-inspects an injected connector, fails on plan drift, and requires adapter authorization and durable reservation before its one external effect. Delivered, rejected, and unknown remain distinct observations. Exact replay returns a current durable observation; reservation conflict blocks; unknown is never retried automatically.

No inbound room event creates, claims, approves, cancels, retries, completes, or starts an assignment.

## Acceptance

Focused tests must cover:

- Exact deterministic planning.
- Source, event, artifact, publication, connector, destination, and workstream blocking.
- Malformed and contradictory evidence rejection and default no-authority behavior.
- Inspect-before-reserve sequencing and durable reservation validation.
- Idempotent current replay and no second delivery.

Quality, type, package-boundary, build, full tests, documentation and knowledge lifecycle, foundation checks, and task-base release completion must pass with reviewed minor release intent.
