# GLA9: Verified post-promotion improvement observation

An exact evaluation protocol is pre-registered during development-pattern review. A post-promotion treatment observation binds to the same candidate, review, target, adapter, metric set, and exact promotion event. Under fixed version-1 policy, the pure controller reports favorable, unfavorable, no-material-difference, and insufficient observations.

Canonical events and CAS retain the protocol and comparison; the current view is a bounded, rebuildable projection. The stock CLI has no measurement authority. An injected versioned adapter verifies rate observations and keeps native evidence private. Attribution remains unestablished. Unfavorable evidence requires review and never authorizes automatic rollback, self-modification, truth promotion, or claims that a provider model learned.

## Acceptance

Focused tests must cover:

- Pre-promotion registration and exact adapter reinspection.
- Baseline and treatment verification; timing and target drift blocking.
- Deterministic comparison and insufficient-sample separation.
- Privacy allowlisting and default no-authority behavior.
- Idempotent event replay and rebuildable projection.
- No automatic rollback.

Quality, type, package-boundary, build, full tests, documentation and knowledge lifecycle, foundation checks, and task-base release completion must pass with reviewed minor release intent.
