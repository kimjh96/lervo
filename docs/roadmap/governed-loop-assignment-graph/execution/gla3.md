# GLA3: Prepared completion reconciliation

Privacy-bounded completion preparation is recorded after managed verification and writing-publication acceptance, before ordinary assignment finalization. Matching preparation permits an exact report-bound plan/apply reconciliation without rerunning provider work. Missing or stale preparation remains escalation-required. Lease expiry alone never makes a completed attempt claimable again.

## Acceptance

Focused tests must cover:

- Canonical run and result binding; foreign or malformed preparation rejection.
- No reclaim after verified completion and explicit no-write planning.
- Exact stale-plan recheck and expired-original-lease recovery.
- State rollback when reconciliation-event persistence fails.

Quality, type, build, full tests, documentation and knowledge lifecycle, foundation checks, and task-base release completion must pass with reviewed minor release intent.
