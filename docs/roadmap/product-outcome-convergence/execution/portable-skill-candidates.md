# Runtime portable-skill candidates

State: `historical`

Superseded by: [ADR-0533](../../../decisions/knowledge/repository/canonicalization/patterns/0533-remove-the-development-pattern-pipeline.md). The implementation below is historical. Background practice learning remains planned.

Independently verified repeated workflows become reviewable portable-skill candidates. Terminal finalization creates a CAS-bound development-pattern candidate only from independently grouped current sources and distinct passed verification events. Retrieval selection alone never establishes candidacy.

The installed journey covers exact review, supersession, promotion, authorization, migration, activation, invocation, completion, and post-promotion observation.

Preserve exact source, verification, skill, resource, input, output, tool, permission, provider, platform, and role contracts.
