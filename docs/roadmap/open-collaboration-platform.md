# Open collaboration platform

Status: `proposed`
As of: 2026-10-04

## Outcome

Deliver the operating experience in [ADR-0452](../decisions/foundation/0452-open-collaboration-by-default-with-authority-at-consequential-effects.md): an owner-run organization of durable agents that converse, self-organize, keep working and improving, act within the owner's mandate, follow work between the Mac terminal and Discord, and ground and measure every turn on a hardened, provider-neutral, local-first core.

The [strengths matrix](open-collaboration-platform/strengths-matrix.md) records each reference product's strengths, Lervo's advantages, and every adoption's verified status.

Lervo is `converged` only when the six true-Lervo journeys in ADR-0452 section 6 pass on installed Nodes with real Codex, real Claude, and a real guild, each with a boundary regression test. Until then, each entry carries only the ADR-0452 completion label supported by its evidence.
