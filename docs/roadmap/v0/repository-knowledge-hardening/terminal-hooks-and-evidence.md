# Terminal hooks and evidence

- Availability-safe direct Codex and Claude hooks preserve provider settings through exact approval, give immediate one-time Codex `/hooks` trust guidance, and remain non-ready until every provider event is observed. Prompt preparation defaults to compact local context with no provider call and preserves opt-in retrieval through `LERVO_TERMINAL_CONTEXT=retrieval`. Root Stop lifecycle gaps are audited without blocking; malformed endpoint input and attached-worker isolation fail closed.
- Terminal hook contract v2 provides a terminal-only bundle, installs a stable tracked launcher for an integrity-bound host-local runtime, resolves the Git root from provider subdirectories, migrates bare contract-v1 commands, and replay-safely reconciles generated-runtime upgrades without a global CLI `PATH`.
- Privacy-bounded unmanaged terminal history and coverage distinguish preparation and exact output reference from unsupported acceptance, managed delivery, and internal use.
- ADR-0541 adds single-open-turn query selections and selected-path reference proxies. Completion requires focused regression coverage plus an installed Claude Code turn in `axli` that records one agent-query selection and one path mention. Test execution and installed acceptance remain pending for this implementation task; no delivery or use claim follows from wiring.
- Direct compact hooks prepare the configured publication language independently of search hits. Cross-provider regression coverage must retain the English documentation instruction for Korean requests, failed retrieval, and compact-context truncation without changing chat language or claiming document use. Installed activation and actual writing compliance remain separate acceptance checks.
- Renderer-hidden markers retain legacy v1 parsing and distinguish structural publication from full-query snapshot semantics.
- Managed E1–E4 grounding supplies exact-version delivery, output citations, separate metrics, and one local/Hub projector.

ADR-0539 completion requires focused coverage for launcher stability, streaming dispatch, unmanaged availability, integrity rejection, atomic private-store retention, legacy migration rollback, POSIX store trust, missing-file retry, default-path integrity repair, structural installation detection, and resident publication authority. Resident A must preserve CLI B's valid runtime on rescan; ADR-0470 reader preflight must accept it. Windows ACL checks and an old→new→old→new packaged rollout fixture remain open. Installed Mac and WSL acceptance must show CLI upgrades leave tracked bytes unchanged in `lervo`, `flemo` and `axli`, with `UserPromptSubmit` working from a repository subdirectory. Source implementation does not establish that installed acceptance.

Completion requires focused tests for both providers, truthful degraded lines, no fallback reads on healthy prompts, unavailable Git discovery without traversal, shared deadlines, retrieval mode selection and prefetch exclusion, and retained worker isolation after capture, inspection, and checkpoint failures. Tests are written but remain unexecuted under the owner's instruction.
