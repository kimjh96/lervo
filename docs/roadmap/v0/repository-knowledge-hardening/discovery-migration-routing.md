# Discovery, migration, and routing

- Bounded typed discovery covers sensitive logs and provider surfaces. Publication defaults to English with language auditing, bounded navigation, safe stale-output deletion, minimum initialization, and lazy directories.
- Migration supports missing README and AGENTS, a separate CLAUDE bridge, bounded root entrypoints, and current documentation contracts.
- Semantic decision directories, `docs/knowledge`, rollback-safe two-hex registry sharding and compatibility, explicit taxonomy, fail-closed routing, shared-leaf enforcement, and removal of the `foundation` fallback completed.
- Lineage-bound operations were separated into trace, diagnostics, security, services, and storage, including pruned-parent recovery and product-neutral starter taxonomies.
- Repository-wide relocation covers every classifiable active document. Canonical archive and inherited collections remain.
- Routing is semantic ([ADR-0476](../../../decisions/knowledge/documents/0476-route-legacy-documents-semantically-and-never-migrate-application-content.md)): explicit metadata or a recorded no-capability classification places a document, title terms no longer decide, application content with source-reference evidence stays in place, and unclassified documents defer to the background resident without blocking `lervo upgrade`.
- Claude rules and skills were normalized into provider-neutral routes and `.agents/skills`, preserving brace-aware conditions, references, AGENTS routing, and a bounded CLAUDE bridge.
- Destination-bound Node reconciliation supports bounded contiguous-history backfill.
