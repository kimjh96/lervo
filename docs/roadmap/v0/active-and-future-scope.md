# Separate active and future scope

These scopes do not reopen v0 acceptance; each follows its linked ADR and roadmap.

- [Core outcomes](../../product/vision/core-outcomes.md): sets the priority of every scope below. Work proceeds Know, Find, Do, Connect, Collaborate, then Surface. An item is complete only when the owner can observe it in installed use and its live measure moves.
- [Product outcome convergence](../product-outcome-convergence.md): truth ledger for outcomes, evidence, and gaps.
- [CI cost and duration](../operations/ci-cost-and-duration.md): approved shared-build and release-verification redesign; local and hosted acceptance are tracked separately.
- [Release to fleet](../operations/release-to-fleet.md): fix to every host without a manual deploy; host install from the verified release, priority upgrade admission, and `lervo host upgrade --follow`.
- [Foundation hardening](../foundation-hardening.md): completed event compatibility, causal work, resource evidence, adverse-condition proof, and enhancement handoff.
- [Governed loop and assignment graph](../governed-loop-assignment-graph.md): completed history. [ADR-0560](../../decisions/foundation/0560-remove-unused-subsystems-to-harden-the-core.md) removed the governed loop and the packed product-host protocol; graph, attempt, and resource projections over canonical assignments and managed evidence stay.
- [Extensible retrieval](../../decisions/search/engines/0328-make-qualified-lexical-v2-the-product-default.md): qualified lexical-v2 and its reviewed projection plan are the repository-independent default. [Surface convergence](../../decisions/search/engines/0413-close-product-default-lexical-v2-surface-gaps.md) closes prior CLI, managed-work, supervision, fallback, and conversation gaps while preserving explicit reviewed alternatives. External composition remains behind provider-neutral boundaries.
- [Context quality and surface parity](../natural-language-grounding-quality/context-quality-parity.md): source implementation covers applicable rules, multilingual evidence, exact sections and outcome observations across shared terminal and host boundaries. Reviewed real-task quality, recording-resource qualification, release and installed parity remain open.
- Gemini and Copilot bridges.
- [Background reusable-practice learning](../knowledge/background-practice-learning.md): wired in the standalone host, with installed evidence pending. A single verified observation can produce a background candidate for independent agent review and repository-instruction or portable-skill output without turn declarations. Hub typed exchange and installed Mac/WSL acceptance remain open.
- Knowledge follow-up: [branch-safe lifecycle](../knowledge/branch-safe-lifecycle.md) and [normalization renewal](../knowledge/document-normalization-renewal.md).
- [Open collaboration platform](../open-collaboration-platform.md): ADR-0452 reverses closed defaults for conversation, memory, learning, and autonomy, cross-checks, makes reversible, and notifies at consequential effects (ADR-0561), defines completion labels and the seven true-Lervo journeys, and sequences ADR-0453 to ADR-0459.
- [Autonomous background convergence](../knowledge/autonomous-background-convergence.md): local implementation and a private installed no-Hub canary verify independent canonical review, normalization application, baseline debt recovery, and knowledge currency without a later user turn; full installed acceptance and fleet activation remain open.
- External graph databases, embeddings, or Hub semantic services.
- [Organization deployment and fleet contracts](../operations/organization-runtime-credential-sources.md) were removed by [ADR-0560](../../decisions/foundation/0560-remove-unused-subsystems-to-harden-the-core.md); `lervo upgrade` owns the Node stage.
