# Installed concurrency and canary verification

All acceptance items remain open. Source tests do not establish installed behavior.

- [ ] Installed canary evidence proves target byte receipt, current normalization records, bridge/projection currency, semantic debt closure, no-Hub behavior, restart, and live-response latency during busy background work.
- [ ] The standalone Node's owned resident child preserves shutdown and parent-loss cleanup while a fresh human Discord question succeeds during actual background work. [ADR-0441](../../../../decisions/knowledge/repository/canonicalization/0441-isolate-resident-knowledge-from-node-conversations.md) separates execution processes; source tests neither prove installed latency nor resolve independent manifest replacement and task-source drift. [ADR-0442](../../../../decisions/knowledge/repository/canonicalization/0442-isolate-conversation-repository-snapshots.md) moves managed conversation snapshots out of the busy Node event loop after the first installed child rollout still recorded a 30-second snapshot failure.
- [ ] Installed managed conversations and background materialization share the repository source gate from [ADR-0444](../../../../decisions/knowledge/repository/canonicalization/0444-serialize-knowledge-materialization-with-managed-runs.md). A fresh published conversation keeps its snapshot stable during active convergence. Deferred reviewed apply retries and reaches current after the conversation settles. Process exit or an interrupted journal recovers without accepting an unmanaged source change.
- [ ] While the developer keeps committing, installed convergence commits each settled normalization apply or canonical integration at the next batch boundary, regenerates a smaller batch after a review timeout, records concurrent scan changes as `stale` rather than `knowledge_source_unsafe`, and reports a live materialization owner as `busy`. [ADR-0465](../../../../decisions/knowledge/documents/0465-commit-settled-knowledge-documents-at-batch-boundaries.md) requires focused tests but does not report their completion. Its 2026-10-05 account places the installed Mac's last knowledge-output commit at 03:49 UTC on 2026-10-04 and describes the next 25 hours. The working tree accumulated 37 reviewed outputs, including normalization rewrites and records from a `normalization_apply` at 00:31 UTC and integrated canonical drafts. This does not establish that all 37 outputs were uncommitted for 25 hours.
- [ ] A host whose seeded delegation names an integration ref it never created starts that ref at `HEAD` and settles canonical integration without manual ref repair. An untyped stage failure shows its attempt count and next attempt time, then records `attention_required/knowledge_stage_failure_unclassified` after four attempts instead of retrying for eleven hours. [ADR-0472](../../../../decisions/knowledge/documents/0472-start-absent-integration-refs-and-bound-untyped-stage-failures.md) requires focused tests but does not report their completion. On 2026-10-06 the Mac `argo` obligation repeated `retry_scheduled` for more than two hours on missing `refs/heads/argo/knowledge-integration`.
- [ ] When every pending normalization document lies outside delegated normalization roots, installed status reports `knowledge_normalization_outside_delegation` with the excluded roots; the owner's extended delegation or normalization exclusion resumes convergence. [ADR-0474](../../../../decisions/knowledge/documents/0474-name-normalization-documents-outside-the-delegation.md) requires focused tests but does not report their completion. On 2026-10-06 the Mac `argo` obligation reported only `knowledge_authority_unavailable` for eleven pending `v4/` documents.
- [ ] A rejected document or canonical source never stops an installed obligation: it is regenerated with the reviewer's reasons, parked after bounded attempts, and every other stage finishes with `knowledge_sources_parked` naming it. Lifecycle plan review stays within its bound despite large unrelated repository text, and undeclared opaque assets reach verified currency as suite-bound. [ADR-0479](../../../../decisions/knowledge/semantics/0479-park-rejected-semantic-candidates-and-settle-opaque-assets-by-the-delegation-suite.md) requires focused tests but does not report their completion. On 2026-10-06 the WSL owner host had `lervo`, `flemo`, and `digimon` stopped on one rejection, `axli` on a 1.96 MB lifecycle review, and `plen` on 58 undeclared PNG assets. After the ADR-0479 deploy, `axli` stopped again because its plan disclosed a stale 4.86 MB generated inventory. [ADR-0481](../../../../decisions/knowledge/semantics/0481-bind-generated-projections-by-hash-in-lifecycle-plan-review.md) binds generated projections by hash and requires a focused regression and a pure test, without reporting their completion.
- [ ] After a knowledge PR squash merge, installed convergence moves the absorbed integration ref to `HEAD` without an owner command and records `knowledge.integration_target.absorbed`. A verification suite that rewrites tracked files reports `knowledge_verification_modified_sources` with exact paths. [ADR-0482](../../../../decisions/knowledge/semantics/0482-absorb-squash-merged-semantic-candidates-and-type-verification-source-changes.md) requires focused tests but does not report their completion. On 2026-10-06 `shiflo` waited on `canonical_target_diverged` after squash-merged PR #47, and `flemo`'s `gate` suite rewrote `pnpm-lock.yaml` under `knowledge_stage_failure_unclassified`.
- [ ] After a runtime deploy, every settled stall is reevaluated once without an owner command, no resident waits on full-cycle admission behind one repository for more than one stage, and a rejected lifecycle plan is parked while assessment continues. [ADR-0485](../../../../decisions/knowledge/semantics/0485-reevaluate-settled-semantic-candidates-once-per-evaluation-contract.md) requires focused tests but does not report their completion. On 2026-10-06, 20 minutes after deploy, five residents waited on one `lervo` cycle, `axli` stopped on a rejected layout plan, and `digimon` retried an untyped `not_initialized`.
- [ ] A canonical or normalization review whose bound context changed is regenerated without attention; a resident idles between due stages instead of repeating complete repository observation after every stage. [ADR-0486](../../../../decisions/knowledge/semantics/0486-regenerate-stale-semantic-candidates-and-reuse-repository-observation.md) requires focused tests but does not report their completion. On 2026-10-06 `digimon` stopped on a rewritten `docs/knowledge/documentation.md` context, and the lervo resident held about one core. On 2026-10-07 the ADR-0486 runtime still settled `digimon` as `review_context_stale` because the owner's pre-stage check preceded regeneration. [ADR-0490](../../../../decisions/knowledge/semantics/0490-regenerate-stale-semantic-candidates-before-the-pre-stage-check.md) moves regeneration ahead of that check.
- [ ] A delegation that pinned a package manager's lockfile as an opaque asset drops it in the next same-scope rebind, commits the cleaned manifest as settled output, and passes the repository's asset suite again after a dependency update. [ADR-0491](../../../../decisions/knowledge/semantics/0491-never-pin-tool-generated-files-as-assets-and-memoize-the-role-registry.md) requires focused tests but does not report their completion. On 2026-10-07 `shiflo` stopped on `Asset hash changed: bun.lock`.
