# Installed concurrency and canary verification

- [ ] Installed canary evidence proves target byte receipt, current normalization records, bridge/projection currency, semantic debt closure, no-Hub behavior, restart, and live-response latency during busy background work.
- [ ] The standalone Node's owned resident child preserves shutdown and parent-loss cleanup while a fresh human Discord question succeeds during actual background work. [ADR-0441](../../../../decisions/knowledge/repository/canonicalization/0441-isolate-resident-knowledge-from-node-conversations.md) separates execution processes; source tests do not prove installed latency or resolve independent manifest replacement and task-source drift. [ADR-0442](../../../../decisions/knowledge/repository/canonicalization/0442-isolate-conversation-repository-snapshots.md) also moves managed conversation snapshots out of the busy Node event loop after the first installed child rollout still recorded a 30-second snapshot failure.
- [ ] Installed managed conversations and background materialization share the repository source gate from [ADR-0444](../../../../decisions/knowledge/repository/canonicalization/0444-serialize-knowledge-materialization-with-managed-runs.md). A fresh published conversation keeps its snapshot stable during active convergence. Deferred reviewed apply retries and reaches current after the conversation settles. Process exit or an interrupted journal recovers without accepting an unmanaged source change.
- [ ] While the developer keeps committing, installed convergence commits each settled normalization apply or canonical integration at the next batch boundary, regenerates a smaller batch after a review timeout, records concurrent scan changes as `stale` rather than `knowledge_source_unsafe`, and reports a live materialization owner as `busy`. [ADR-0465](../../../../decisions/knowledge/documents/0465-commit-settled-knowledge-documents-at-batch-boundaries.md) covers these with focused source tests only; the 2026-10-05 Mac fleet had 37 settled outputs uncommitted for 25 hours before this decision.
- [ ] A host whose seeded delegation names an integration ref it never created starts that ref at `HEAD` and settles canonical integration without manual ref repair. A stage failure without a typed code shows its attempt count and next attempt time, then records `attention_required/knowledge_stage_failure_unclassified` after four attempts instead of retrying for eleven hours. [ADR-0472](../../../../decisions/knowledge/documents/0472-start-absent-integration-refs-and-bound-untyped-stage-failures.md) covers these with focused source tests only; on 2026-10-06 the Mac `argo` obligation repeated `retry_scheduled` for more than two hours on the missing `refs/heads/argo/knowledge-integration`.
- [ ] When every pending normalization document lies outside the delegated normalization roots, installed status reports `knowledge_normalization_outside_delegation` with the excluded roots, and the owner's extended delegation or normalization exclusion resumes convergence. [ADR-0474](../../../../decisions/knowledge/documents/0474-name-normalization-documents-outside-the-delegation.md) covers this with focused source tests only; on 2026-10-06 the Mac `argo` obligation reported only `knowledge_authority_unavailable` for eleven pending `v4/` documents.
- [ ] A rejected document or canonical source never stops an installed obligation: it is regenerated with the reviewer's reasons, parked after its bounded attempts, and every other stage still finishes with `knowledge_sources_parked` naming it. Lifecycle plan review stays within its bound in a repository with large unrelated text, and undeclared opaque assets reach verified currency as suite-bound. [ADR-0479](../../../../decisions/knowledge/semantics/0479-park-rejected-semantic-candidates-and-settle-opaque-assets-by-the-delegation-suite.md) covers these with focused source tests only; on 2026-10-06 the WSL owner host had `lervo`, `flemo`, and `digimon` stopped on one rejection, `axli` on a 1.96 MB lifecycle review, and `plen` on 58 undeclared PNG assets. After the ADR-0479 deploy, `axli` stopped again because its plan disclosed a stale 4.86 MB generated inventory; [ADR-0480](../../../../decisions/knowledge/semantics/0480-bind-generated-projections-by-hash-in-lifecycle-plan-review.md) binds generated projections by hash, again with focused source tests only.
