# Background reusable-practice learning

Status: `planned`
As of: 2026-10-25

Lervo should learn reusable practice from repeated verified work. [ADR-0533](../../decisions/knowledge/repository/canonicalization/patterns/0533-remove-the-development-pattern-pipeline.md) removes the unused declaration-driven pipeline while retaining this goal. A later design should follow background instruction capture and owner review from ADR-0467.

## Completion criteria

- Observe learning candidates in the background from repeated verified work.
- Have the owner review candidates before promotion.
- Produce repository instructions or portable skills through the appropriate reviewed authority.
- Require no turn declaration.

The design must work locally without a Hub, preserve exact evidence and user-owned content, and never interrupt the developer. Provider behavior stays behind adapters. This item authorizes no implementation or background writes.
