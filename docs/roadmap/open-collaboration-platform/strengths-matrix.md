Where Lervo is slower by design, it is because the slower step is the differentiator: canonical knowledge changes only through exact review (criterion 12), promotion needs verification, and consequential effects need authority. Everything before those steps is now open.

## Deliberately rejected reference behaviours

- A Paperclip-style company database as repository truth, issue checkout replacing path leases, heartbeat completion as evidence, mixed activity and evidence records, uncertain-effect retry without an idempotent contract, opt-out telemetry, and company vocabulary in the neutral core ([safeguards](../../research/paperclip-lervo-comparison/safeguards.md)).
- Monetary estimates presented as billed cost; hard stops before telemetry coverage is measured ([operating model](../../research/paperclip-lervo-comparison/recommendations/operating-model.md)).
- Buzz-style membership or mentions expanding filesystem, network, provider, budget, or write authority ([collaboration and mentions](../../research/paperclip-lervo-collaboration-and-mentions.md)).
- Prime-style self-modification of the core; refinement stays a reviewed candidate ([adaptable ideas](../../research/lervo-product-positioning-and-verified-improvement/product-lessons/adaptable-ideas.md)).
- Hermes-style hidden personal memory as truth; memory is agent-scoped and non-canonical ([Hermes differentiation](../../research/lervo-product-positioning-and-verified-improvement/product-lessons/hermes-differentiation.md)).
