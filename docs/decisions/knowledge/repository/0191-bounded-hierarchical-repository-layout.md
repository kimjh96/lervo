# ADR-0191: Bounded hierarchical repository layout

Status: `accepted`

As of: 2026-08-23

## Context

Separating independent topics prevents append-only documents, but flat directories can still become unbounded catalogs. Lervo also published human navigation at repository-root `knowledge/`, separating related material from `docs/` without making it internal state.

Human documentation needs stable semantic neighborhoods. Content-addressed machine registries need deterministic distribution independent of subjective classification.

## Decision

- Keep human-readable source and generated navigation under visible `docs/`, not hidden `.lervo` control state.
- Use `docs/knowledge` as the default generated publication root. Move existing generated bytes through the structural migration plan and protect them with generation manifests.
- Move decisions from flat `docs/adr` into configured routes under `docs/decisions`. ADR numbers retain identity. Migration uses the tracked taxonomy before requiring exact per-document approval.
- Limit each decision leaf to 24 ADR documents. Lifecycle checks reject flat legacy ADR directories and overfull leaves.
- Store ID-addressed registries and rebuildable state with two-hex fan-out: `<registry>/<digest-prefix>/<artifact-id>.<extension>`.
- Readers accept legacy flat artifacts during migration but reject duplicates and incorrectly sharded records. Writers emit only canonical sharded paths.
- `lervo migrate knowledge` moves legacy machine artifacts without user-byte approval; user documents require exact item approval.
- Apply, rollback, and deletion prune empty directories. Initialization creates only directories required by existing files.

## Consequences

The repository retains a short, visible documentation surface while `.lervo` contains policy, provenance, generated manifests, and local state. A clean clone can rebuild machine indexes from canonical content, and registry directories do not grow linearly with history.

ADR-0192 refines the classifier: routes are repository-scoped, and classification fails closed instead of falling back to `foundation`.
