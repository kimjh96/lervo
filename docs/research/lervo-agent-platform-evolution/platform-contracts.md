# Product boundaries and platform contracts

Lervo's product and platform boundaries cover:

- [Product construction](platform-contracts/product-construction.md): product surfaces, connector authority, local observation, and the minimal reference surface.
- [Graph foundations](platform-contracts/graph-foundations.md): implemented graphs and canonical authority.
- [Governed loops and execution graphs](platform-contracts/governed-loops.md): bounded execution, recovery, and graph evolution.
- [Headless application contract](platform-contracts/headless-application.md): shared public contracts for replaceable applications.
