# Coordination and authority

The multi-team operating report is a read-only composition of repository-owned projections. The executive policy evaluator is a pure decision boundary: it checks the named agent's appointment to the executive responsibility, action and team allowlists, automation depth, budget observation, report integrity, and approval. It never performs an effect.

An installed organization-executive coordinator binds an allowed decision to one exact effect and a durable replay coordinate. Discord channel and thread creation use the Discord administration adapter; future Lervo UI actions can use another adapter without changing organization policy. Verified completion records a receipt, explicit rejection terminates, and uncertain delivery never auto-retries.

Ordinary agent conversation remains read-only unless an existing authority path creates or changes an assignment, workstream, approval, or external effect. Bounded discussions reuse Lervo deliberation for evidence, disagreement, decision rules, and termination; Discord supplies distinct visible speakers.
