# Repository knowledge

A bounded scanner, typed source adapters, and a deterministic structural compiler project repository evidence without assuming folder names. Isolated capability-free providers may propose source-cited normalization candidates. Reviewed Markdown and existing semantic records remain canonical; [ADR-0529](../../../../decisions/knowledge/semantics/0529-remove-the-semantic-compilation-pipeline.md) removed semantic compilation.

```text
repository sources
  -> typed inventory + stable source units
  -> structural plan -----------------> bounded publication + sidecars
  -> lint / impact / query / context delivery
```
