# Repository knowledge

A bounded scanner, typed source adapters, and a deterministic structural compiler project repository evidence without assuming folder names. Isolated capability-free providers may propose source-cited semantic or normalization candidates. Reviewed Markdown and semantic records remain canonical.

```text
repository sources
  -> typed inventory + stable source units
  -> structural plan -----------------> bounded publication + sidecars
  -> isolated semantic compiler
  -> reconcile -> human review ------> claims, relations, semantic pages
  -> lint / impact / query / context delivery
```
