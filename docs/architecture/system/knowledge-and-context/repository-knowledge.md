# Repository knowledge and document ownership

## Repository knowledge

A bounded scanner, typed source adapters, and deterministic structural compiler project repository evidence without assuming folder names. Isolated capability-free providers may propose source-cited semantic or normalization candidates. Reviewed Markdown and semantic records remain canonical.

```text
repository sources
  -> typed inventory + stable source units
  -> structural plan -----------------> bounded publication + sidecars
  -> isolated semantic compiler
  -> reconcile -> human review ------> claims, relations, semantic pages
  -> lint / impact / query / context delivery
```

## Document ownership

Every document has one write model: user-owned bytes, exact managed blocks, or proven Lervo-generated output. Provider entrypoints retain user regions. AGENTS carries only a fixed-size registry bootstrap; CLAUDE imports it through a managed bridge.
