# Direct provider terminals

Direct provider terminals use a narrower native-hook path. Every prompt performs a fail-closed query and receives exact-hash context. Stop checks knowledge currency and may observe exact context-reference markers. New markers are standalone Markdown HTML comments; legacy plain v1 tokens remain accepted.

Privacy-bounded preparation, reference, and turn events prove neither provider acceptance nor internal use. They cannot satisfy managed E1–E4 because Lervo did not create or fully observe the provider process.

Terminal integration merges approved handlers into Codex and Claude hook configuration without replacing provider settings. Invalid or conflicting configuration blocks migration.

Opaque coordinates bind prompt and Stop events without raw provider IDs or conversation text. An exact managed worktree binds one writer and generation without claiming managed-provider telemetry.

Direct hooks prepare at most 8 KiB and retain bounded coordinates. Unattached and integrator Stop require global checkpoints for changed revisions. Worker Stop validates its workspace, writer, lease, and scoped diff and records a private checkpoint; foreign global movement is informational.
