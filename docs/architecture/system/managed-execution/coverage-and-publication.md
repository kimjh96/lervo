# Coverage and publication

`@lervo/context-coverage` projects managed coverage once from canonical events. Enhanced E3 binds injected receipts to exact document versions. Validated adapter results retain only their digest and turn coordinates; exact returned tokens may create E4 output citations.

Evidence-bearing sources and human publication have separate coordinates. Only current-envelope evidence metadata is removed before publication evaluation and storage.

Local and Hub projections use the same projector and never equate delivery or citation with understanding or internal use.
