# Headless application boundary

The headless application boundary rebuilds assignment graph, attempt, resource, completion-evidence, and operating-attention projections. Root heartbeat evidence, inspected through `lervo agent inspect`, and managed-process point-in-time evidence remain separate.

`@lervo/application-contract` owns public shapes. Pure projectors compose existing authorities without bypassing lease, approval, verification, event, or recovery rules.

[ADR-0560](../../../decisions/foundation/0560-remove-unused-subsystems-to-harden-the-core.md) removed the next-action governed loop, the bounded unattended scheduler, the operating liveness report, and the product-host protocol. `lervo application attention` is the remaining application query.

See the [specifications and decisions](../managed-execution.md).
