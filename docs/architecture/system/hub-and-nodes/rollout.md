# Node apply and upgrade

Installed Nodes use deterministic project, repository, and Node identity. An owner-only local registry binds root, destination, runtime, service, and health coordinates without credentials. Exact apply transactionally installs or upgrades, requires three stable complete observations, then registers. `lervo upgrade` owns the Node stage of a repository upgrade.

Organization enrollment, wave rollout, signed rollout delivery, recovery, and predecessor rollback were removed by [ADR-0560](../../../decisions/foundation/0560-remove-unused-subsystems-to-harden-the-core.md).
