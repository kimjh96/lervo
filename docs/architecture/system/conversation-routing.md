# Natural-language conversation routing

Status: `active`

The installed Node separates Discord transport, normalized identity, participation policy, semantic intent, managed response, remote continuation, publication, and durable evidence. Platform adapters do not choose repository effects; provider adapters do not enter conversation or authority contracts.

- [Routing, identity, and evidence](conversation-routing/routing-and-authority.md): intent resolution, provider selection, and authority boundaries.
- [Transport and recovery](conversation-routing/transport-and-recovery.md): Gateway control, history reconciliation, typing, and durable response retries.
- [Deployment composition](conversation-routing/deployment-composition.md): configuration, runtime ownership, and multiple bot deployments.
- [ADR-0388](../../decisions/coordination/conversations/0388-realtime-conversation-effects-and-lifecycle.md): realtime publication, scoped platform effects, lease ownership, and conversational status prose.
- [ADR-0389](../../decisions/coordination/conversations/0389-single-managed-conversation-turn.md): one managed turn, shared repository retrieval, and surface-neutral effect declarations.
- [ADR-0391](../../decisions/coordination/conversations/0391-deterministic-multi-agent-turn-ownership.md): deterministic participant and role ownership before typing or provider work.
- [ADR-0392](../../decisions/coordination/conversations/0392-installed-proactive-signals-and-deliberation.md): bounded repository-event wake-ups and installed managed deliberation.
- [ADR-0394](../../decisions/coordination/conversations/0394-webhook-backed-discord-agent-identities.md): shared Gateway transport and distinct webhook-backed hired-agent identities.
