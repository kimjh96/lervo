# Capability packages

Local capability packages are lazy, immutable project- or user-scoped directories. A provider-neutral resolver validates hashes, compatibility, role permissions, exact dependency graphs, discovery metadata, MCP runtime descriptors, and native plugin manifests, then writes a rebuildable lock.

Telemetry distinguishes recommendation, selection, verified loading, provider activation, skill invocation, and completion. Agent records bind exact package coordinates; subagents inherit and may narrow them.

After controlled injection, adapters translate requests into native configuration and confirm MCP connection or plugin load before the task turn.
