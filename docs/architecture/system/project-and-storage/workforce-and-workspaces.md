# Workforce and workspaces

Owner-only workforce and workspace coordination state resides under the Git common directory so sibling worktrees share one scheduler. Non-Git checkouts use a standalone compatibility home. Legacy migration rejects competing non-empty authorities.

Versioned role contracts, ancestry hashes, bounded delegation, atomic path leases, and exact handoff evidence govern root agents and subagents. Workspace lifecycle is local; Orca and Hub are optional. Apply rechecks authority, and uncertainty requires recovery.

The [project and storage entrypoint](../project-and-storage.md) links the workspace specification.
