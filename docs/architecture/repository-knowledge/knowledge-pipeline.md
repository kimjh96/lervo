# Knowledge pipeline

A bounded scanner discovers sources without assuming folder structure. Adapters extract stable file, section, key, symbol, revision, verification, event, and skill-contract units. A deterministic structural compiler builds a bounded knowledge map and sidecars. Isolated, capability-free Codex or Claude compilers may produce source-cited semantic or normalization candidates.

## Routing and storage

Human documentation stays under `docs/`, including `docs/knowledge`; `.lervo` holds policy, provenance, manifests, and rebuildable state. `.lervo/knowledge/document-layout.yaml` routes decisions, documents, and canonical instructions through explicit metadata or recorded semantic classification, never title keywords. Unclassified documents defer to the background resident instead of blocking. Markdown consumed by its own workspace package is never moved.

Provider-neutral behavior belongs in `docs/instructions/<route>` and portable Agent Skills in `.agents/skills`. Machine registries use deterministic two-hex fan-out while retaining legacy flat-path reads. `foundation` is never an implicit fallback.

## Normalization and currency

Normalization produces bounded English Markdown for an audience profile with complete source-section coverage. Every source requires exact approval. Content-bound shard caches and a three-process ceiling keep runs bounded and resumable without weakening compiler-build or source binding. Planning revalidates inner bindings and the complete current source set.

Lifecycle sidecars bind output hashes, format and language versions, compiler build, and skill-resource hashes. Changed documents or skills become stale without automatic rewriting.

## Publication

Markdown and repository state are canonical; graphs, lexical indexes, and embeddings are rebuildable. Generated indexes use a reduced structural snapshot excluding runtime evidence, revision metadata, verification results, and local-only agent surfaces. Full query snapshots may differ without implying staleness; the current migration plan and manifest determine currency.

Tracked policy selects language (`en` in v1), entry bounds, and byte bounds. Large categories become short page trees; obsolete recorded pages are safely deleted.
