# Terminal projection

For unmanaged direct terminal preparation, query projection is limited to registered knowledge in the current repository. Empty or failed projection has no evidentiary meaning for another repository or an external or shared service. Source expansion requires a separately available tool and authority; keyword, synonym, translation, or phrase routing never establishes it.

Production terminal projection opens one capability-free provider runner and performs one query-producing model turn, without the historical synthetic admission turn. The provider-neutral projection port, digest and query bounds, isolated Codex thread, serialized Claude process, usage receipt, and owner-close contract remain unchanged. Provider lifecycle details stay outside search core.
