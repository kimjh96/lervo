# Installed Node activation

An installed Node may opt into organization delivery with one explicit organization Node ID. Before reading the existing owner-only bearer file, the application binds each grant to that ID, the loaded repository identity, and its Hub destination.

The application verifies the candidate through the authenticated project-registration exchange before replacing the running token. Failure preserves the prior in-memory token and creates no receipt. Credential mutations are exclusive.

Activation proves neither every permission nor synchronization, readiness, later use, durable file rollback, or rollout.
