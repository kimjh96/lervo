# Runner boundaries

The runner's executions, including semantic evaluations, share one cached repository-snapshot capture. The default finalization reserve is 50,000 ms. After preparation and coordinator construction, an abort timer uses the admitted allowance. A caught failure after the timer fires becomes an elapsed-budget error. The timer is always cleared.

Optional verification preparation selects the requested suite. Non-evaluation roles gain the `deliberation.task-evidence` requirement. An accepted participant binding must match the selected provider; participant model and reasoning settings override provider defaults. The coordinator permits zero tool calls and zero command executions. These are configuration limits, not evidence of provider compliance.

Human-facing roles receive the workspace writing policy; machine-facing roles do not. With a causal parent, work causality records the relationship, parent coordinates, optional attempt ordinal, and bound agent identity.

After usage accounting succeeds, result bytes are loaded from CAS, decoded as strict UTF-8, and checked against the declared byte count and content hash before content is returned.
