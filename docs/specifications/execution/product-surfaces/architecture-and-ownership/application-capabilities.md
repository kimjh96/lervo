# Product application capabilities

The versioned boundary grows through cohesive capability groups:

- Conversation participation, threads, replies, mentions, and origin correlation.
- Goal admission, planning, supervision, result publication, and source handoff.
- Activity subscription and bounded history.
- Operating queries for objectives, staff, work, blockers, approvals, verification, usage, and cost.
- Live-steering commands for amend, pause, resume, cancel, approve, retry, reassign, and handoff.
- Optional formal deliberation start, inspection, resume, decision projection, and origin-bound delivery.
- Typed unified search and source inspection.
- Collaboration artifacts, canvases, files, media, and workflow projections.

Each command retains its owning domain authority and idempotency. A surface must never convert a query, message, room membership, search result, or button press directly into authority.
