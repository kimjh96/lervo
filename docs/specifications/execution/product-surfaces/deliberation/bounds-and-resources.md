# Deliberation bounds and resources

Managed deliberation binds resource limits, immutable evidence, provider capabilities, recovery, and verified participation through these contracts:

- [Limits and accounting](bounds-and-resources/limits-and-accounting.md): authoritative budgets, call feasibility, shared snapshot capture, and usage accounting.
- [Evidence and capabilities](bounds-and-resources/evidence-and-capabilities.md): immutable repository evidence and provider tool boundaries.
- [Failure and evaluation recovery](bounds-and-resources/recovery.md): terminal failures, uncertain outcomes, and bounded evaluation retries.
- [Provider-proven participation](bounds-and-resources/participation.md): artifact verification, convergence, and provider claims under [ADR-0460](../../../../decisions/coordination/deliberation/0460-trigger-tiered-deliberation-at-decision-points.md).
