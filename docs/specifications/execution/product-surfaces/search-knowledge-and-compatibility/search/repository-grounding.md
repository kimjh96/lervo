# Repository grounding

Every product surface uses the resolved repository-context composition. Qualified Lexical v2 is the product-default repository-knowledge ranker. An explicit reviewed repository selection may choose another qualified engine or complete retrieval plan. Selected-adapter failure fails closed; product composition must not silently use Lexical v1.

Long-running hosts prepare once and query many times for one exact repository source revision. Revision changes invalidate the projection.

Returned ranking evidence includes engine, version, and adapter build. It must not claim that a provider loaded, referenced, understood, or used a result.
