# Direct hooks

Direct Codex/Claude hooks use a self-verifying, repository-local contract-v2 runtime with exact-hash loads up to 28 KiB.

Preparation applies provider-neutral projection and qualified Lexical v2 only to registered repository knowledge. It records `unmanaged_terminal_retrieval_only` without semantic-action coordinates, effect, workflow, authority, external route, or durable rule. It creates no managed run and proves no acceptance, understanding, or use.

Empty or failed retrieval proves nothing else. Internal failure returns empty success without evidence. Managed execution stays typed and fail-closed.

The lifecycle cache binds CLI version, repository revision, supplemental-source digests, and generated-projection digests. Any change invalidates it.

Direct root `Stop` records bounded lifecycle and reference observations when possible. Non-current state records `action_required` with completion `allowed`. Unmatched or failed audits return empty success without evidence.

Agents still update workstreams and declarations after changes. Attached workers retain fail-closed isolation. Reference tokens are standalone Markdown HTML comments; legacy v1 tokens remain valid in flight.

A current workstream must match its latest event and CAS artifact. Managed runs load exact bytes before E3. Direct hooks prepend at most 8 KiB and record bounded identity, revision, hash, byte, and scope coordinates. Missing or stale direct state is a finding, not permission or completion evidence.
