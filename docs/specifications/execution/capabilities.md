# Capability package supply chain

Status: `active`
As of: 2026-08-25

The capability supply-chain contract covers:

- [Local packages](capabilities/local-package-contract.md): immutable manifests, discovery, installation, and reader limits.
- [Resolution and activation](capabilities/resolution-and-activation.md): authority, provider receipts, and execution evidence.
- [Repository migration](capabilities/repository-migration.md): skill promotion and provider-owned configuration.
- [Optional Hub distribution](capabilities/hub-distribution.md): approved publication and retrieval.
- [Evidence and privacy](capabilities/evidence-and-privacy.md): canonical state, disclosure exclusions, and receipt boundaries.

The [events and privacy specification](events-and-privacy.md) defines workforce state disclosure. [ADR-0210](../../decisions/execution/orchestration/0210-local-first-capability-package-supply-chain.md) records the supply chain; [ADR-0211](../../decisions/execution/providers/0211-provider-confirmed-capability-activation.md) records provider activation.
