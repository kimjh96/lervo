# Entrypoints and Language

README provides concise human onboarding; AGENTS provides concise provider-neutral guidance; CLAUDE is a thin AGENTS bridge. Generated publications use a versioned catalog and tracked language. Normalization uses that language and a versioned profile; v1 supports English. Neutral localized titles preserve exact encoded paths.

Repository upgrade treats an instruction-bridge binding made stale solely by an ordered AGENTS or CLAUDE rewrite as a bounded transitional finding. The next generated-only stage must refresh the bridge binding. Upgrade must not claim completion before convergence; final deterministic knowledge lint remains mandatory.

Human writing binds `publication.language` to `writing_en-human`, semantic checks, policy hash, evaluation, and permit. Deliberation carries locale through profiles, prompts, verdicts, evaluation, and publication. Unsupported locales fail before execution; provider prose never implies approval.

Initialization creates minimum configuration; feature and state directories remain lazy. Durable local data and rebuildable projections follow the state lifecycle specification.
