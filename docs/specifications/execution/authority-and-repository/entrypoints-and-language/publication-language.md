# Publication Language

Generated publications use a versioned catalog and tracked language. Normalization uses that language and a versioned profile; v1 supports English. Neutral localized titles preserve exact encoded paths.

Human writing binds `publication.language` to `writing_en-human`, semantic checks, policy hash, evaluation, and permit.

Deliberation carries locale through profiles, prompts, verdicts, evaluation, and publication. Unsupported locales fail before execution; provider prose never implies approval.
