# Adapter Telemetry

Adapter telemetry covers these contracts:

- [Native events and usage](telemetry/native-events-and-usage.md): event normalization, usage, and constrained results.
- [Managed process observation](telemetry/managed-process-observation.md): process evidence and orchestration boundaries.
- [Linked-evidence selection](telemetry/linked-evidence-selection.md): canary eligibility and ordinary managed-run selection.
- [Selection-only Responses transport](telemetry/selection-only-responses-transport.md): optional transport requirements and runtime acceptance facts.

Process-observation decision: [ADR-0372](../../../decisions/execution/orchestration/0372-observe-managed-provider-process-state-through-adapters.md).
