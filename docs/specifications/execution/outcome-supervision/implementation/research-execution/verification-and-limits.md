# Verification and operational limits

Common coordinator tests cover both provider adapters, private input exclusion, corrupt or missing CAS input, and incompatible event writers. CLI tests cover original-byte verification and placeholder-command rejection.

Node integration tests use a real CLI checker, separate controlled provider runs, and a runtime restart: supported results complete, while unsupported claims with valid provenance return for rework.

These controlled tests do not establish signed-in provider quality, installed Discord journeys, or production activation. Those remain separate delivery evidence under the outcome-supervision acceptance plan.
