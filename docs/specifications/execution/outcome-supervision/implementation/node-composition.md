# Node supervision composition

`openNodeOutcomeSupervisionRuntime` composes the provider-neutral controller with repository mandate authority, canonical event/CAS journals, and SQLite owner leases. Binding requires the supervision ID, workstream ID, owner agent ID, and installed mandate hash.

CLI installation uses the Node authority-source adapter and requires an active workstream. For recovery, supervision may inspect the current completed or blocked workstream.
