# Research inputs and independent acceptance

Research execution binds a question, explicit source policy, captured source bytes, exact result verification, and independent semantic judgement. The current source-policy version supports repository files. Network research requires a separately reviewed source and permission contract.

- [Repository source policy](research-execution/source-policy.md): permitted files, captured inputs, and context delivery.
- [Input and result evidence](research-execution/input-and-result-evidence.md): input binding, provenance, and the installed verifier.
- [Independent acceptance](research-execution/independent-acceptance.md): evidence reconstruction, semantic evaluation, and completion admission.
- [Verification and operational limits](research-execution/verification-and-limits.md): test coverage and delivery evidence boundaries.
