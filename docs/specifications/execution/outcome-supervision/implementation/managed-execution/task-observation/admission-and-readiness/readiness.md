# Canonical filesystem readiness

For filesystem-only managed tasks, readiness loads actual workforce authority, Git workspace, and instruction/search bytes. These permission and context observations pass the existing mandatory login, executable, tool, path-access, knowledge-currency, and pinned-verification probes.

Context loading does not claim injection or use. Other capability mappings, including network source policy and shell execution, remain unsupported in this canonical path.

Production owner planning, recovery, and publication adapters require separate admission.
