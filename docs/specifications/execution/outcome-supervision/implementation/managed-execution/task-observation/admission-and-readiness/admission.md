# Canonical admission and resource accounting

Admission derives the managed effect from exact CAS bytes, verifies responsibility, observes active assignments and attempts, and reads recorded decision reservations. It also derives exact automatic topology, responsibility-claim and owner-control effects. Structural allocation and responsibility acquisition do not establish provider readiness. Built-in adapters revalidate repository sources at fenced transitions.

- [Decisions and reservations](admission/decisions-and-reservations.md) defines accounting blockers and exemptions. Superseded managed dispatch uses the version-four empty-run or version-five exact reservation-only envelope in [worker execution](../../worker.md).
- [Goal resource observation](admission/goal-resource-observation.md) defines causal coverage and aggregate comparability, including the narrow default-model proof in [ADR-0400](../../../../../../../decisions/execution/orchestration/governed-work/0400-prove-default-model-supervision-budget-comparability.md).
