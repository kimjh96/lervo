# Review evidence and acceptance

Review observations must follow the current responsibility binding and terminal event and match the current owner. A review under an earlier mandate remains observable only if its installation precedes the event in the verified successor chain ending at the current mandate.

The reader reopens the exact admitted owner decision and CAS effect under the review's original mandate through [canonical artifact review](../../artifact-review.md). The entrypoint-relative reference is `../artifact-review.md`. A bare review event is insufficient.

The controller separately checks the reviewer, acceptance criteria, exact artifact set, and mandatory verification references. Without review, acceptance remains pending even if verification passes.
