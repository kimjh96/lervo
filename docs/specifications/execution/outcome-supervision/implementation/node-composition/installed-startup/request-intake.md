# Installed supervision request intake

An active installed owner can bind one request to its current workstream through local stdin or its configured Discord speaker. Both use the same Node intake under the exclusive owner lease. Admission identifies the current installed goal; it does not imply creation of an unrelated goal.

- [Binding, evidence and refusal contract](request-intake/binding.md)
- [Discord routing, provenance and pending authority](request-intake/discord.md)
- [Standing lineage and successor intake](request-intake/standing-lineage.md)

Intent-routed Discord intake follows [ADR-0410](../../../../../../decisions/execution/orchestration/governed-work/0410-intent-routed-supervision-goal-intake.md). Standing lineage selected by `outcomeSupervision.standing` follows [ADR-0405](../../../../../../decisions/execution/orchestration/governed-work/0405-standing-supervision-lineage.md).
