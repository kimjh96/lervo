# Installed supervision request intake

An active installed owner can bind one request to its current workstream through local stdin or its configured Discord speaker. Both call the same Node intake under the exclusive owner lease. The writer checks the current mandate, workstream revision, assignment graph and latest event hash before appending `work.supervision.bound`. The event records supervision, owner, mandate, workstream revision, graph hash, snapshot cause, request artifact hash and acceptance artifact hash. It does not record request text, external message IDs or participant IDs.

The request artifact stores the bounded text, source kind, source and requester digests, content hash and, for Discord, an exact result origin. The acceptance artifact pins the workstream objective, snapshot and assignment IDs at admission. Both use local CAS. An exact replay of the same source and content returns its existing event; a changed source or second origin for that goal fails closed. A failed or unobserved commit does not authorize replaying a provider effect.

Discord routing uses this path only when its durable responding agent ID equals the installed owner ID. The conversation intent and effect-request authority checks still precede intake, and the responder rechecks human or explicitly admitted agent authority. The accepted result is published to the bound source origin through the existing independently reviewed result-delivery path. The immediate response proves only that canonical binding succeeded. Local `--request-stdin` avoids request text in process arguments and runs the same owner loop after binding; local results remain canonical without external publication.

Binding an unrelated request to an existing objective is not a goal amendment. A new objective, revised acceptance criteria, or additional recipient needs a separate workstream and authority transition. Installed production acceptance must observe the real ingress, owner cycle, permission recovery, accepted result and delivery under settled authority.
