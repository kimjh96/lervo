# Grounded workforce planning

- [Grounded planning](workforce-planning/grounded-planning.md) defines repository evidence, workforce matching, staffing selection, and provider observations.
- [Canonical task observations](workforce-planning/canonical-task-observations.md) defines `SupervisionTaskSource`, observation consistency, audit limits, and evidence boundaries.

The native owner composes model task decomposition, exact allocation, [scoped hiring](worker-hiring.md), and separate workspace preparation/dispatch. Borrowing, reassignment, and production activation retain independent authority and acceptance requirements.

Converting canonical task facts into a complete supervision snapshot and connecting [managed execution](managed-execution.md) remain application responsibilities.
