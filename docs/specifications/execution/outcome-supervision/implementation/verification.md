# Verification boundary

Controller tests cover scope and budget expansion, unknown resources, expiry, revocation, stale role and responsibility bindings, saving and verification readiness, silent failures, uncertain effects, finite recovery, artifact acceptance, canonical completion, cancellation, and independent result publication.

Composition tests use in-memory port implementations and cover duplicate owners, unchanged idle sources, restart recovery, revocation between recording and execution, unavailable write scope, and persisted start deadlines.

These fixtures do not prove SQLite persistence, installed Node behavior, provider execution, Discord delivery, or cross-repository handoff acceptance.
