# Local decision attention

`work.owner_attention.v1` records one concrete decision need against the owner's exact semantic task basis. It uses `work.supervision.escalation.recorded`, with the local owner as recipient, a bounded reason code, the exact decision-plan artifact hash, and no scheduled retry. The rationale artifact states the missing decision. This records local follow-up responsibility without claiming external delivery or central acceptance.

The unchanged basis waits across restart without another model call. A canonical goal, staff, task, review, or relevant peer change invalidates that basis and permits fresh planning. Existing authority and escalation limits still apply. Publication remains a separate receipt-backed operation.
