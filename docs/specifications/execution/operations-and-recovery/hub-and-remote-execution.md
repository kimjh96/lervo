# Hub and Remote Execution

Hub and Node coordination is authenticated, scoped, policy-bound, and network-neutral. Signed organization policy adds tenancy and split issuance/delivery authority. Secret-free grants bind policy, target, permissions, generation, and time. Inactive or revoked grants fail before load; source bytes are cleared after loading, and receipts exclude material. Local execution remains independent.

Repository Node apply revalidates inputs and registers after three stable complete observations. Organization enrollment binds that evidence to active credential delivery.

Rollout uses a one-Node canary, at-most-twofold waves, zero unavailable tolerance, and separate planning, approval, execution, and rollback; records claim no effect. Failure restores the predecessor or requires explicit rollback. User/provider bytes, trust, credentials, publication, onboarding, and legacy transitions retain separate authority.
