# Governed-loop projection

The governed-loop graph is rebuildable and adds no durable graph state. Its report replays current assignment state and existing causal, run, verification, and resource events. Approval requirements leave the report only as digests.

Verified approval observations bind opaque assignment, authority, approval, evidence-hash, and validity coordinates. They exclude requirement text, approver identity, signatures, credentials, and evidence bodies.

A next-action decision remains a projection, not an approval, assignment mutation, provider invocation, or completion event.
