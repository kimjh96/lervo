# Managed execution and operations

`lervo run` separates document and knowledge searches. Selected sources require current-byte validation and adapter delivery receipts; later use is not inferred.

External products use `lervo application capabilities --json`. Protocol v3 adds read-only liveness with separate agent and process evidence. Protocol v4 adds reviewed-input message triggering and explicit recipient-coordinate acknowledgment, keeping route, delivery, and action separate. It grants no UI, database, scheduler, implicit approval, provider, recovery, or connector authority.

- [Capabilities](execution/capabilities.md): local packages, evidence, migration, and Hub exchange.
