# Knowledge CLI inventory: current evidence boundary

Status: `documentary_correction; command_inventory_unverified`

This amendment governs [Advertised command families](advertised-commands.md). The supplied assessment does not include `knowledge-usage.ts`, command registration or handlers. The assertion that its complete list describes the current usage string is withdrawn. Preserve that list as an unverified historical interface description, not current executable guidance.

## Patterns and retained contracts

The supplied [repository knowledge specification](../../specs/repository-knowledge-compilation.md) explicitly marks the development-pattern lifecycle historical under ADR-0533. Accordingly, the Patterns bullet in the advertised inventory must not be presented as a supported current workflow. Its proposal, review, promotion and effect options are not verified instructions for current use.

ADR-0533 itself was not supplied. This correction therefore does not assert its exact removal scope, identify surviving aliases, or infer a replacement command. The specification says instruction capture and typed canonicalization assessment remain active and practice learning is wired in the standalone resident; that statement does not verify CLI syntax for those responsibilities.

[ADR-0529](../../decisions/knowledge/semantics/0529-remove-the-semantic-compilation-pipeline.md) explicitly retains `lervo knowledge materialize --recover` and removes the semantic compilation pipeline and review-ID materialization form. This supports the recovery operation's contract. It does not independently verify the advertised optional root and JSON flags or current handler execution.

## Remaining inventory

The Refresh, Canonicalization, Normalization, Workers and convergence, Structure, Freshness, Instructions and OKF bullets remain unverified descriptions of names and options. Neither this amendment nor the older inventory establishes their exact current parsing, approval requirements or implementation behavior. They must not be promoted to verified command instructions merely because related canonical responsibilities exist.

A verified current inventory requires the exact usage owner, registrations and relevant handlers, reconciled with ADR-0533 and subsequent applicable amendments. Help text can establish advertising only; handler inspection and execution evidence are separate requirements for enforcement and observed behavior.

This correction preserves the original document and withdraws unsupported current guidance without inventing replacement syntax. No command was executed, and no runtime, lifecycle-test, packed-smoke, deployment or publication result is claimed.
