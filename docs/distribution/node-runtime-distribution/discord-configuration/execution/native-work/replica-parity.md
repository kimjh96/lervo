# Optional replica parity and completion

Replica parity is optional by default. Strict single-writer deployments require exact peer parity before native work and after changed work.

- [Default and strict topology](replica-parity/topology.md): configuration, ownership and divergence.
- [Coordinator bounds and watches](replica-parity/coordinator.md): transport limits, change detection and idle recovery.
- [Readiness and completion](replica-parity/completion.md): receipt checks and successful publication.
