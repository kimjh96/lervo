# Execution and evidence boundaries

Native work may inspect and change repository bytes. For ordinary requesters, execution instructions prohibit commits, pushes, deployment, broad deletion, and secret disclosure.

An authenticated human or configured effect requester may explicitly request one commit, push, remote creation, or exact-target deployment. Deployment requires a rollback, current runtime and authority checks, and installed verification. It grants no risk-limit increase, kill-switch reset, or credential change.

These are policy instructions, not operating-system sandbox guarantees.

Results report paths Git observes as changed without claiming exact-path verification by a managed run. Native work never uses fixed queue text.
