# Resolve cross-host conflicts through coordination, not host restriction

When Lervo features conflict between a Mac host and a WSL Hub host, do not propose or apply restricting Lervo to operate on only one host as the solution. Lervo must behave identically on whichever host work happens; treat such conflicts as a cross-host coordination problem and solve them through coordination.
