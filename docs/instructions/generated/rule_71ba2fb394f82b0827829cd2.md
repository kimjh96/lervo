# Lervo never silently passes a check it could not finish

Lervo must never silently pass a check it could not finish. When a coordination claim, a turn-end reconciliation, or another Lervo verification runs out of time or fails, Lervo must not report the work as allowed or done as if it had been checked: it completes the check (in process or later), or refuses with a visible reason, and records the miss where the owner and agents can see it.
