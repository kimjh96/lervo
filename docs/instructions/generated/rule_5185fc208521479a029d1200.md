# Remove the legacy retrieval context mode and keep compact context as the only path

The owner approved removing the legacy retrieval context mode from the hooks, so that compact context is the single context-building path. Agents find documents on demand through the repository knowledge query instead of having document bodies injected at prompt time. The retrieval mode was kept only as an environment-variable fallback, nothing enables it outside some tests, and the duplicate path adds maintenance cost and bug risk.
