# Agents mention each other directly; the product owner is not a router

Agents mention each other directly as their work needs, by role and by what each has learned, not only through the product owner. Every agent has its own role, so any agent may mention any other agent in the project to work efficiently; the product owner is not a router for agent-to-agent work, and is mentioned only when its role (priorities, decisions) is needed.
