# Move all projects from ~/orca to the Lervo projects location when the Lervo ADE replaces Orca

When the Lervo ADE replaces Orca, the owner stops using the folders under ~~/orca. Every project there moves to the Lervo projects location (~~/Lervo by default) with its registry entry, worktrees, and Lervo state following it, and nothing new may depend on a path under ~/orca.
