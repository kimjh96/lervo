# Lervo ADE must use the Lervo core fully

The Lervo ADE must use the Lervo core fully. Every core guarantee that holds for a terminal session must hold for an ADE session: context delivery, turn evidence (selected, loaded, injected, referenced, used), knowledge query binding, owner instruction capture, workstream continuity, usage accounting, and memory and recall. Before designing an ADE feature, inventory the existing core mechanisms it touches and build on them; add a new mechanism only with a written reason why the core mechanism does not fit. Every ADE verification checks the core records, not only the visible behavior. An ADE that bypasses the core gives no reason to use it.
