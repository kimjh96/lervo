# Evidence-bound improvement observations

Status: `active`

Before collection, define each improvement metric's counting unit, denominator, canonical evidence source, privacy handling, unavailable states, and failure meaning. Never interpret missing evidence as zero.

Register baseline evidence while the pattern is under review and before promotion. Collect treatment evidence only after the exact promotion event and while the bound target and adapter contract remain unchanged. Never backfill a baseline around an already promoted pattern.

Use genuine repository activity as outcome evidence. Controlled fixtures may verify mechanics, but must not be presented as production or repository outcomes. Do not manufacture no-op work to meet a sample threshold.

Keep observation separate from authority: collection is read-only. Neither a favorable comparison authorizes promotion nor an unfavorable comparison authorizes rollback. Retain `attribution: unestablished`; proxy rates do not establish causation, correctness, semantic use, truth, or model-weight learning.
