Structural extraction creates navigation and source identity. Semantic candidates require reconciliation and human review.

Migration creates an explicit repository structure and documentation system:

- Documents use repository-scoped semantic routes and reviewed audience-specific formats.
- Behavioral instructions use provider-neutral pages routed from AGENTS.
- Portable skills use `.agents/skills` with resource-bound lifecycle records.
- Provider configuration remains provider-specific.

Moving or rewriting user bytes, including adding Lervo-owned provider hooks, requires exact content-bound approval.
