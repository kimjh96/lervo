# Governed continuation

After foundation readiness, Lervo projects current assignments and managed-run evidence through a provider-neutral headless application contract. Outcome supervision continues accountable work from those projections. Canonical authority remains with workstreams, assignments, leases, events, verification, and repository state.

Automatic supervision topology may add bounded branch-and-join nodes to the current assignment graph. It binds the exact graph and role contracts, creates deterministic blocked assignments before activation, and retains ordinary dependency, lease, execution, and verification authority. It cannot rewire or delete existing nodes.

[ADR-0560](../../../decisions/foundation/0560-remove-unused-subsystems-to-harden-the-core.md) removed the next-action governed loop, the bounded unattended scheduler, and the versioned product-host protocol, none of which had a production invoker. `lervo application attention` remains the local application query.
