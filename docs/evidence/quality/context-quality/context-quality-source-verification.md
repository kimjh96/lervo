The queue freezes each ready group at dispatch, snapshots paths and retains at most sixteen queued or in-flight calls per store. Overflow and paths beyond the native bounds use ordinary I/O before admission. Success and failure both release capacity, and late callers never share completed or running results.

Kernel results retain `created` and a `complete`, `large` or `failed` status. `complete` supplies at most 65,536 bytes, which JavaScript must hash before returning success. `large` supplies no partial body and selects a fresh ordinary observation and complete read. Streams and larger inputs keep ordinary publication and synchronization. `failed` carries `code`, `errno`, `syscall` and `pathIndex`; translation preserves system error coordinates and maps target-observation absence to `not_found`, while later open/read/close absence remains a system error. Unsafe type or identity observations remain `unsafe_path`. A missing prefix parent falls back to the existing recursive mkdir only when native mkdir failed before linking. Original temporary cleanup and the independent verification reread remain intact.
