## Result and source boundaries

The [investigation](knowledge-maintenance-recovery-and-speed-design.md) found empty directory evidence, indefinitely held technical candidates, queued-work starvation, and repeated expensive status/preflight work. The first implementation addresses these paths without enabling concurrent canonical effects.
