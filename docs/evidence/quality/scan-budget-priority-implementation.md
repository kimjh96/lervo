## Result and boundaries

The scanner inventories candidate sizes, admits sources by the ADR's five classes and host-neutral admission order, and records sources that do not fit as `unsupported / total_budget_exceeded`. Later small sources may use the remaining budget. Results carry `coverage` and `skippedForBudget`; the previous numeric aggregates remain available as `inventoryCoverage`. The policy default, individual-file behavior, supplemental adapter bounds, and hard file-count stop remain unchanged.

Query JSON and text report partial coverage and skipped classes alongside hits. The publication loader cannot reread a budget-skipped document. Cross-file skill-contract validation does not read a package with a budget-skipped resource. Privacy classifications and inventory-only provider surfaces retain their existing handling.

Currency paths use complete-scan admission, including prepared and virtual inputs. They stop with `knowledge_source_limit_exceeded` and retain one replaceable owner-only private diagnostic containing skipped counts, bytes, and classes, without source paths or content. Stateless compilation refuses partial input before provider calls and carries the same summary on its private error. Repository-aware callers persist that evidence. No new event is introduced.

ADR-0537 retains its core decisions and ADR-0535 reference. Review clarified the distinction between deterministic admission and compatible output ordering, plus complete coverage admission. No finding invalidated the core decision. The release intent is `minor` because query output gains coverage fields.
