## What's changed

- Account for every deferred migration document and classify routes during provider-backed migration.
- Authenticate native skill observations and worker entries, gate new events on reader activation, and bind attribution to the closing revision.
- Bind each workstream to a branch so concurrent sessions keep separate objectives, branch switches stay fresh, and Hub replication follows the default-branch workstream.
- Bind terminal knowledge queries to the single open turn and observe selected document paths as reference proxies.
- Bound managed Node runtime retention and reclaim unreachable convergence artifacts during local background maintenance.
- Correct practice-learning privacy, read scope, retry scheduling, reader compatibility, retained reviews, command outcomes, and unused-skill exposure.
- Defer document freshness without spend or a rejected candidate when the provider fails before any model call.
- Detect installed provider CLIs at background run time and admit executable identities by the no-capability contract, with allowed fallback and visible waiting.
- Extract source units from TypeScript declaration files, so a repository with .d.ts, .d.mts, or .d.cts files no longer fails knowledge lint and query.
- Index repository scan units by source, removing a quadratic lookup that kept the knowledge resident on a full CPU core in large repositories.
- Keep background knowledge moving past document capacity and optional context read failures.
- Keep background knowledge moving when an approved draft meets divergent integration-target bytes: park its sources, return discarded drafts on the integration ref, report pending normalization as non-blocking attention, and surface owner-host convergence stops.
- Keep repository knowledge queries available under scan byte budgets and report partial coverage.
- Keep terminal hook software in a private host store behind a stable tracked launcher, with automatic runtime repair and legacy artifact migration.
- Keep terminal hooks within a shared budget and retain base context with private failure reason codes.
- Keep user documents out of the Git-ignored knowledge publication root, warn about unrecorded files there, and explain in generated AGENTS.md that the knowledge index is local.
- Learn portable practice skills from observed completed work with independent review, delegated publication, and version-bound usage assessment.
- Name every owner rule whose body does not fit in the terminal hook context, so crowded prompts no longer drop rules silently.
- Observe native repository skill invocations in the knowledge resident and project usage for retirement review.
- Point terminal prompts at the skills, decisions, and nested instructions they name exactly, after owner rules and without a provider call.
- Re-probe provider pauses without reset times on bounded backoff, preserve newer failures, and expose pause age and next eligibility.
- Record skill invocation and completion only when a run delivers the verified skill body; resolution-only hosts record resolution alone.
- Remove development-pattern and role-candidate commands while preserving historical event reads and existing skills.
- Remove the always-empty reviewed relation projection from knowledge query JSON and the graph counters from managed run search summaries.
- Remove the retired linked-evidence canary and the shadow observation that ran on every managed run and conversation.
- Remove the unused semantic compilation pipeline: lervo knowledge compile, compare, stability, merge-candidate, fuzzy-merge-candidate, reconcile, review-policy, review, and materialize <review-id>; materialize --recover stays.
- Replace compact review chores with cached Know and Find health and actor-attributed operating attention.
- Report unbuilt knowledge in fresh clones from query, lint, and the first terminal prompt, and build it in the background when the build writes only Git-ignored outputs.
- Retain bounded resident cycle failure diagnostics and surface their codes in continuity attention and doctor JSON.
- Use one provider dispatch context, inspect continuity admission state read-only, and continue fallback after native re-probe failures.
