Needs the Lervo CLI 0.43.0 or later.

## What's changed

- Paste or drop files and folders into the reply card and the instruction of new work: they wait as file chips beside images, go to the agent as their paths, and show as chips in the message.
- Show a banner for every turn notification: each notification now has its own identifier across launches, so Notification Center no longer updates an older one silently.
