Needs the Lervo CLI 0.43.0 or later.

## What's changed

- Add projects with named actions: Add Project opens a menu with Open Folder, Clone Repository, and New Project; Clone and New open a centered glass window with one field and a folder button for the location, and the first run offers the same three as cards.
- Projects in the sidebar: a switcher with each project's logo or first letter, its workspaces only, Command-1 to 9, in-place rename, and a context menu to change the logo, show the folder, or remove the project from Lervo. New work goes into the selected project.
- Show a quiet line when an agent runs lervo project add or lervo project location.
- Show a quiet line when an agent runs lervo project show, rename, or mark set|clear.
- Show a quiet line when an agent runs lervo repository unregister.
- Sidebar rows line their labels up at one edge, project logos keep one shape at both sizes, New work shows once a project exists, and the start screen no longer shifts while the lists load.
- Space opens and closes with what comes and goes: notices, errors, the attachment tray, tool details, and workspace rows slide the content around them instead of jumping.
