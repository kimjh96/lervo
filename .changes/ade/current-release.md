Needs the Lervo CLI 0.69.0 or later.

## What's changed

- A code block's long lines scroll inside the block instead of widening the conversation past the window, the working line fades while earlier turns are read under it, and an agent's answers elsewhere show one line per conversation.
- A conversation shows when an agent sent work to a teammate's conversation, and the lead's conversation shows who sent it and from where; each line opens the other conversation.
- Scrolling back through a long conversation keeps the reader's place when earlier pages, joined agents' items, or answered lines land above it, and estimates unmeasured rows closely, so the view no longer jumps or flickers.
