# First use

From the repository root, run `lervo init --name my-project`. The [CLI package usage contract](../../../docs/decisions/release/packaging/0090-cli-package-usage-guide.md) defines this example. The [onboarding guide](../../../docs/roadmap/onboarding/agent-workforce.md) explains review and authority boundaries.

For an existing repository or a newer CLI, follow the [repository upgrade guide](../../../docs/roadmap/onboarding/repository-upgrade.md). For migration, query, and lint, see [repository knowledge](../../../docs/specs/repository-knowledge-compilation.md).
